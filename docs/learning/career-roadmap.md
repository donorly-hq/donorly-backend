# Career Roadmap

Track: Senior Java Backend Engineer → AI-Enabled Backend Engineer → AI FDE → GenAI/Agentic AI Architect.
Source: Donorly AI Engineering Learning Companion (July 2026). Donorly is the learning laboratory:
each product capability teaches one production skill.

## 12-week execution plan (current)

| Weeks | Donorly deliverable | Skill acquired |
|---|---|---|
| 1-2 | docs/ + ADRs + ownership reviews of existing code | Architecture ownership |
| 3-4 | Harden pledge→payment→receipt with tests | Transactions, testing discipline |
| 5-6 | donorly-ai FastAPI skeleton (Zahed writes the Python) | Python, FastAPI, Pydantic, Pytest |
| 7-8 | Evidence-backed summaries + draft-for-approval follow-ups | Structured outputs, cost logging |
| 9-10 | pgvector RAG + golden dataset | Embeddings, retrieval, evaluation |
| 11-12 | Weekly Fundraising Review (approval-based agent) | Agentic workflows, guardrails |

## Months 4-9

Advanced RAG and guardrails → tool calling and richer agents → production AI architecture
(observability, cost, scale, resilience) → iterate with a real design-partner organization.
